# TV-Skin — a calm custom launcher for Samsung Tizen TVs

A replacement home screen for Samsung Smart TVs: full-screen public-domain artwork, a clean app dock, an all-apps grid, and remote-friendly navigation. Built and tested on a 2021 Tizen 6.0 TV (Chromium 76 web engine).

## Start here
1. Read **`CLAUDE.md`** — project map, toolchain, build steps, and the hard-won gotchas (signed install, Chromium-76 fixes).
2. Open `prototype/index.html` in Chrome to play with the launcher on your computer.
3. To put it on your TV you need Developer Mode, Tizen Studio, and **your own** Samsung certificate tied to **your** TV's DUID (see CLAUDE.md).

## Fill in your own values
Search the repo for these placeholders and replace them:

| Placeholder | What it is | Where to find it |
|---|---|---|
| `YOUR_TV_IP` / `<your-TV-IP>` | Your TV's LAN IP | TV: Settings › General › Network › Network Status |
| `YOUR_MAC_IP` / `<your-Mac-IP>` | Your computer's LAN IP (Developer Mode host + debug collector) | System Settings › Network |
| `YOUR_CERT_PROFILE` / `<your-cert-profile>` | Your Samsung certificate profile name | Tizen Certificate Manager |
| `YOUR_TV_DUID` / `<your-TV-DUID>` | Your TV's unique device ID (goes into your distributor cert) | TV: Settings › Support › About This TV |
| `YOURPKGID0` | Your 10-character Tizen package id | Generated by `tizen create web-project …` |
| `<your-TV-model>`, `YOUR_FIGMA_FILE_KEY` | Reference only | — |

The main edit points are marked `>>> EDIT … <<<` in `launcher-app/device-build/build.sh` and `launcher-app/CleanFrame/config.xml`.

## Known limits
- Sound-output and HDMI-input switching can't be done from an app on this TV generation (no API; the network remote never authorizes app connections). Details in `HANDOFF-CLAUDE.md`.
- The web UI renders at 1080p and is upscaled on 4K panels.
- Home-button takeover needs temporary root and is documented separately in `HOME-BUTTON.md` — use at your own risk.

Artwork is public domain (The Met, Art Institute of Chicago, Cleveland Museum of Art).
