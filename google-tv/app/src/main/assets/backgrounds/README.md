# Default background

`all-apps.jpg` is a 3840×2160 landscape photograph served by Unsplash, image `photo-1470770841072-f978cf4d019e`.

Source: https://images.unsplash.com/photo-1470770841072-f978cf4d019e

It appears when All apps is highlighted, and as the fallback when an app has no shared image or its image cannot load. It is a static default, not an artwork screensaver.
